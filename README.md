# 📱 Gerenciador de Eventos - Frontend Native

Aplicativo móvel para gerenciamento de eventos desenvolvido em React Native. Permite que administradores gerenciem seus eventos de forma simples e intuitiva.

## 🚀 Funcionalidades

### Autenticação
- Login de administrador com email e senha
- Cadastro de novos administradores

### Gerenciamento de Eventos
- Visualização de eventos em lista com imagens
- Criação de novos eventos
- Edição de data e localização
- Exclusão de eventos
- Visualização de detalhes do evento

## 🛠️ Tecnologias Utilizadas

- React Native
- React Navigation
- Axios
- Context API
- Styled Components

## 📋 Pré-requisitos

- Node.js (versão 14 ou superior)
- npm ou yarn
- React Native CLI
- Ambiente configurado para React Native

## 📱 Telas

### Login
- Campo para email
- Campo para senha
- Checkbox "Lembrar-me"
- Botão de login
- Link para cadastro

### Cadastro
- Campo para nome
- Campo para email
- Campo para senha
- Campo para confirmação de senha
- Validação de dados
- Feedback de sucesso

### Home
- Lista de eventos
- Imagem do evento
- Nome do evento
- Data e localização
- Botões de ação (editar/excluir)
- Botão para adicionar novo evento

### Modal de Evento
- Campo para nome
- Campo para data
- Campo para localização
- URL de imagem
- Botão de salvar
